# download
Download Page Untuk LLM-Y

## Quick Start

**Windows (PowerShell):**
```powershell
iex (irm https://raw.githubusercontent.com/llm-y/download/main/run.ps1)
```

**Linux / macOS:**
```bash
curl -fsSL https://raw.githubusercontent.com/llm-y/download/main/run.sh | bash
```

Script akan otomatis mendeteksi arsitektur (amd64/arm64), mengunduh binary, menginstal ke PATH, dan menjalankan rprompt.
